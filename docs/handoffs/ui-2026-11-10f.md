## Interpretations (please confirm or change)
1. **Hover text: "ends" and "pays".** The task says "the state it ends in ... and what that state pays". D54 fixes a
   node's rewards at the click. So the tooltip shows both:
   - "4 h · ends Warm": the state after the node's hours;
   - "Pays Clear: ...": the state the node is entered in (`pays`), which is what this node pays.
2. **The meter's place.** It sits over the action bar's right half, and the Autoplay controls moved to the left half.
   - This is the one band that no screen panel, frame, ruler, engage panel or window reaches at 16:9.
   - A top-centre bar would have collided with the target frame, the ruler, the boss frame and the map window.
3. **Loot raised a rarity: an interim lookup in the bridge (`heatSteps`).** The engine does not mark the step on the item
   (engine-api.md 11.3). So after a step that rolled items in a node entered Hot or Scorched, the bridge asks the engine
   the same step with the node entered Clear. The engine guarantees that the heat draw is always made and that the loot
   stream does not depend on heat (rules 8.4), so the same items roll, and an item whose rarity differs is one heat
   raised.
   - It runs only in Hot or Scorched nodes, only when the step rolled gear, and copies the state with
     serialize/deserialize.
   - Any failure marks nothing.
   - **Engine request:** put a mark on the item or the `loot` event (for example `heatUp: 'hot'`). Do the same on node
     reward choices. The bridge would then drop `heatSteps`.
4. **"Nothing pays at the camp".** H.3 says the camp pays no heat rewards. The engine's `heatView` gives `gain` and
   `rarityUp` of the state there anyway, so the meter takes "pays nothing" from `zone.camp`.
   - **Engine request:** a flag on `heatView` (for example `pays: false` at the camp and in the boss fight) would let the
     UI stop knowing this.
5. **Summary end line.** "Hours over par" is shown when the run reached the camp (hours - `bossPar`). A run that died
   earlier shows its end against that zone's line.
