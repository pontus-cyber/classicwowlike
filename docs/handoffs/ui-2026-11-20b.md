# UI hand-off 2026-11-20b: junk out of the loot loop

Role: UI/UX & Visual Engineer. Status: **draft**. Source: ui-2026-11-20 open item 2 (tester s0426), BACKLOG 2026-11-20 follow-ups.
UI only. No file in src/engine, src/content or sim/ changed, and game.html was not touched. Applies with Legacy on and off.

## What changed
| # | Item | Change | Where |
|---|---|---|---|
| 1 | Junk sold at the next vendor | When a vendor opens (hub Vendor or a vendor node), the junk in the bags is sold in the same step with the engine's own `SELL_JUNK`. One log line carries the total: "You sell 4 junk items for 64 copper." Nothing is logged when there is no junk. The "Sell junk" button is then never shown (junk is gone before the window is read); the per-item Sell rows stay for gear | engine-bridge.js `step` (after the action's switch); ui-text.js `junkSoldName` (draft) |
| 2 | Same junk once per loot window | Junk pieces with the same name that wait in a loot window (or already went into the bags in the same spoils) show as one row with a count: "Torn Pelt ×2". Take acts on every piece the bags can hold (pieces of one name stack into one slot), Drop and Leave act on all of them. Waiting and taken rows stay apart. The engine's loot window still holds one entry per piece, so `LOOT_CLOSE` and the replay log are unchanged | engine-bridge.js `stackJunk`, `LOOT_TAKE`, `LOOT_DROP`; screens.js `buildLoot` |
| 3 | "Leave N items behind" | N counts pieces (a stack of 3 counts 3), the same as the engine's loot window | screens.js `buildLoot` |

Bag stacking itself already existed (engine `addToBag`: same name and level stack up to 10), so no engine change was needed.

## Sim records
No engine, content or sim file changed (`git diff --stat origin/main` lists src/ui, qa, docs only), so sim records on any seed are identical by construction. The bridge's extra SELL_JUNK is a UI action that the engine log records; the sim bot (autoplay) already sells junk at a vendor on its own.

## Open items
1. Junk is sold only when a vendor opens (the only place the engine allows a sale). Junk therefore still fills bag slots between vendors; stacks of 10 keep that small. A rule that sells junk on pickup would need an engine change and a design decision.
2. The loot rows of a junk stack larger than 10 would show one row; the bags split it into slots as before.
