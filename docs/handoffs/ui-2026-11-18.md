## 4. Known issues and open items
1. **Engine (open):** `R.shownLevel` on a spell's learn level is one too low for 14 spells (e.g. Shadowstep Strike power 4
   shows 2, but hero 2 has power 3; Starlance Barrage and Heartseeker Shot power 46 show 19, learned at 20). The UI shows learn
   levels as the first hero level that reaches them (legacy.md 1.7); a `heroLvl` on spells or a `learnLevel(M)` helper in
   rules.js would move that rule into the engine.
2. **Engine (open):** the zone danger lines ("enemies here deal up to +N % damage") read `R.zoneDanger` only; ZONE_TIER_DMG is
   not in any view, so a Legacy zone's extra damage is not shown.
3. Item levels show up to 29 (ILVL_MAX_HERO 69), the engine hand-off's open item 1.
4. The classic rows map's travel texts stay on power levels (a Legacy run plays the expedition map).
5. The word swap acts on every text `h()` builds while a Legacy profile is shown, content lines included ("Echoes" in
   content's nudge and camp lines read "Legacy points"); texts set with `textContent` are swapped where they name Echoes (the
   Hall's ticker). The refund note bypasses it on purpose.
6. Talent text in a Legacy run is a UI draft line, not content (texts.progress could get its own id).
