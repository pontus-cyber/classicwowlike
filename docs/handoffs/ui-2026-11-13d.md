## 3. Item 10's origin
"WIND-UP R3 null" came from tracks.js `windupBanner` (line 322 before the fix): `box.append(h('span.wu-b', ...), lethal ?
lethalBadge() : null, h('span.wu-t', msg))`. The native `Element.append` turns `null` into the text "null"; util.js `h` and
`add` skip it. A non-lethal wind-up printed it. Now `add(box, ...)`. The Furnace's note in heat.js had the same pattern
and is fixed the same way. Not in the engine view.
