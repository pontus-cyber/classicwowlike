node qa/browser/ui-regress.mjs --file /tmp/ui-game.html                       # both sizes, about 2 min

## Notes for QA and the Lead
- full-run.mjs compares the UI with a Node twin after every action. The twin does not know the item-bar auto-placement (BUG-QA-04), so after the first purchase or loot of a combat consumable with a free slot, the UI's item bar can differ from the twin's until the QA policy sends its own SET_ITEM_BAR. The twin should apply the same rule after each action: first free slot, only for an id that was not in the bags before, `use` any or combat, Mana Draught only for mana users [inference: from reading full-run.mjs; not run].
- Selectors QA uses still work: `#actionbar .toggle` (now the switch button), `.ab[data-slot]`, `.ab[data-islot]`, the "Face Oruvath" and "Set out" buttons, the bag menu labels.
- The screenshots in docs/handoffs/screens/ predate the hub and camp footers; not regenerated (no polish task). Current camp and hub: run ui-regress.mjs with `--shots`.
