## 1. The rule (rules 1.9.9 item 3, D162)
`src/engine/autoplay.js` `nodeScore`:
```js
case 'quest': return isLegacy(s) && p.level < node.cl - EA.AUTO_QUEST_LEVEL_SLACK ? S.risky : S.quest;
```
`AUTO_QUEST_LEVEL_SLACK: 3` in `C.ENGINE_ASSUMPTION` beside `AUTO_ELITE_LEVEL_SLACK`. `expScore` returns null for a risky
node, so the policy does not enter the quest and goes on to the next node or leaves. An unseen quest is still walked to;
the gate acts once it is seen. No HP gate. A level-60 run is unchanged. rules.md 1.9.9 item 3 names the rule.
