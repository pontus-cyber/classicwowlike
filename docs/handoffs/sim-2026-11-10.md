## Designer open item: the Satchel anomaly (bot bug, fixed; no engine change needed)
- Cause: the vendor policy counted the 3 Satchel Healing Draughts toward HEAL_STOCK_TARGET, but the item bar holds only Greater draughts while any are held, and autoplay uses only the item bar (rules 7.9). With Alchemist's Notes the bot bought only 2 Greater draughts and reached the end boss with 2-3 usable potions instead of 5.
- Repro (sim 934ab58, engine 0d663d1): rogue, planner, PALL, tree 2, seed 1002, RISK_PRIOR (`--warmup 0`): Greater draughts gone after boss round 17, rounds 23-35 at 23-30 % HP with 3 Healing Draughts in the bag, death in round 36; without Satchel victory. On engine 934ab58 the same holds for seed 1022 (death in round 35). Trace script: sim/out/satchel/trace.mjs (git-ignored).
- Effect (designer's v3a scratch, seeds 1000-1299): rogue PALL planner 59.0 % with Satchel, 83.3 % without; after the fix 87.7 / 86.0 %.
- Lead: nothing for the Engineer. UI note: a human holding both potion kinds must put both on the item bar; the default autopilot buys only plain draughts and is not affected.
