## 3. For the Simulation & Balance Engineer (sim/ not edited)
- **The sim's `setGates` (sim/lib/runner.mjs) turns every `C.GATES` key off unless the cell names it.** With the new
  defaults that means a sim cell without `--gates` plays the v13 engine for rows 1 and 4 (all four switches off), not the
  package as built. To play the package: `--gates rareHpMultZ1,firstMeetWindup,sapHold,passStealth`. Cells of
  changes-m2b-v14.md: cell 1 row 1 on = all four; row 1 off = `rareHpMultZ1,firstMeetWindup`; cell 4 = `rareHpMultZ1,firstMeetWindup,sapHold`
  (passStealth off). `cellName` only marks g5/g6, so give each arm its own `--name` or out dir. A sim-side change to default
  to the engine's values is the alternative (and qa/sim/v13.test.mjs's deepEqual needs the two new keys either way).
- Recorder fields: none new. A rule-H wait is a PASS while every living enemy is SAPPED; its Deathblow then ends in a
  `stagger` event with `why: 'control'`, `by: 'SAPPED'`, `deathblow: true`.
- Only autoplay bots (planner, greedy, speedrunner, opener's autoplay candidate and continuation, tactician continuations)
  meet rule H; onebutton and masher never Sap (B59, B62 unchanged by row 1).

## 4. Readings (designer or Lead to confirm; each is one place to change)
1. **Switch names.** Row 1's switches are `C.GATES.sapHold` (a) and `C.GATES.passStealth` (b), the names the spec offers.
2. **`wait` on the Sap answer** needs the wind-up after the enemy's turn 1 (a turn-1 wind-up is cancelled at round 2's
   start with no wait) and every other living enemy SAPPED or dead; it does not depend on `sapHold` (it is the manual
   player's option), `stealth` depends on `passStealth` and the player being in STEALTH. `sure` stays false on it.
3. **The PASS answer** is listed in every round before the wind-up while rule H's condition holds for that wind-up
   (`now` true), for any class; Rogue-only in practice.
4. **Content invariant in the strict validator only.** The structural (non-strict) check that `newRun` runs is
   unchanged, so test fixtures with one elite per zone still load.
5. **First meetings on by default** make every quest fight's first-met normal enemy a wind-up for every caller, the
   engine tests' fixtures included; suites that test the older scripts set the switch off (section 1).
