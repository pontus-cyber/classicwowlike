## Not built, or built differently (for the Lead)
1. **A8 literal check**: the built file holds the SVG namespace identifier `http://www.w3.org/2000/svg` four times (three `createElementNS` calls, one inline SVG data URI in tokens.css). It is never fetched (no request in the campaign), but a plain "no http:// in the file" check fails on it. Proposal: A8 exempts the SVG namespace; the alternative is rewriting those three call sites.
2. **"Next in the hall"** keeps the E6.3 rule of the full game (the first affordable entry in the planner's order, else the cheapest with "N more points"), not "the cheapest affordable, or none". Single-rank entries are named without "I" ("Vigor of the Line").
3. **New draft lines not in the spec**: the zone 2 Road sign reads "End of the demo" (it named zone 3); the Start over note "Deletes your heroes and Legacy unlocks and starts the demo from the beginning."; the second-click label "Start over: click again"; the hero select heading above. All in `DEMO_TEXT` for D.5.
4. The Road in zone 2 now asks before leaving (one dialog, with the demo line); in the full game it still asks only when contracts would expire.
5. **?demo=1 in a team build** gives the demo's rules and storage keys, but settings.js reads its settings before the switch is applied, so that page starts from the full game's stored settings (then saves them under the demo key). The demo build itself is not affected.
6. Not checked here (D.6, QA): the browser matrix, 1920x1080 and 125 %, file:// and iframe cells, reload and save cells, the 120-minute session, heap, frame time, load time; DM1-DM7 (Sim). demo.html is 2.50 MB (under DEMO_FILE_MB_MAX 3).
