## 1. What changed (all behind `C.GATES.legacy`; with it off nothing on screen changes)
| Item | Change | Where | Check |
|---|---|---|---|
| 1 Learn levels | The bridge's `learnOf` is gone; the display hook `lvLearn` is `R.learnLevel(state, M)` (trainer rows, "Next spell at level N", spellbook, Lost Technique texts). Same numbers as the UI's old loop for every spell (0 differ) | engine-bridge.js `view()`, util.js | qa/ui, Y3, Y5 |
| 2 Zone danger | `dangerOf(level, variant, td)` = `zoneDanger × td - 1`; td = `mapView.tierDmg` in a zone (both map modes), `R.zoneTierDmg(s)` at the Camp, 1 outside a Legacy run. The zone view carries `tierDmg` in a Legacy run. A Legacy zone's minimap line and zone banner say its own number (draft): "Enemies here deal up to +N % damage." (none when the product is 1 or less), not the per-10-levels rule. No line in Oruvath's fight (he and his Shards take no tier factor) | engine-bridge.js, ui-text.js `dangerRule(r, z)`, `dangerBanner`, hud.js | qa/ui, Y5 |
| 3 Word swap | Content lines with their own Legacy wording (`prep.unspentFirst`, H37 and every coach line) are appended with `verbatim()` (util.js: a text node without the swap), so content's text is what shows. prep.js's fallback (no content) says "Legacy points" while a Legacy profile or run is shown. The swap stays for the UI's own texts (Hall, buttons) | util.js, onboarding.js `fillLine`, prep.js `unspentLine` | qa/ui |
| 4a Abandon run | Menu and settings (Esc / the Esc micro-button): row "Abandon run" in a Legacy run only (not at class select or the summary). First click asks ("Abandon: click again"), second sends `ABANDON_RUN` and closes the menu. Log line "You abandon the run." The summary reads "Your Rogue left the run", row "Ended: Abandoned from the menu" in place of "Killed by"; "Begin a new run" sends END_RUN, which pays the Legacy points; the hero keeps its level. Bridge: `ABANDON_RUN` action, `summary.death.abandoned` | windows.js, engine-bridge.js, screens.js | qa/ui, Y5 |
| 4b Dev hero level | Dev menu, Give, Profile: "Hero" (class) + "Hero level" (1-25) + Set, with a Legacy profile only; dev op `hero` = `R.debug.setHero(profile, class, { level, xp: 0 })`, at class select only (refused in a run). Not a dev run (profile op, like Give Echoes) | dev-menu.js, engine-bridge.js, app.js | qa/ui, Y5 |

Docs: ARCHITECTURE rows of engine-bridge.js, util.js (`verbatim`), qa/browser (Y5).
