## What changed

- **The catalogue (src/constants.js).** `META_HERO` now holds the v3d hall. Vigor of the Line gives +3 % then +1 % max HP (`HALL_VIGOR_PCT` [0.03, 0.01]). Edge of the Line gives +2 % then +1 % Power (`HALL_EDGE_PCT` [0.02, 0.01]). Both cost 70 / 130. Deeper Pockets gives +8 slots for 50 (`HALL_POCKETS_SLOTS`). Second Breath costs 200 and Stormhawk 90. Every other entry keeps its v2 price and effect. Account entries plus one class's techniques cost 1 650 (Hunter 1 740). The whole hall for one hero costs 2 350.
- **Effects by rank (src/engine/nodes.js `metaFromProfile`).** A list field gives the value of each rank and is summed over the ranks owned. A number field still means "per rank", so META and level-60 runs are unchanged. `state.meta.hpPct` and `powerPct` are still numbers.
- **Gate.** `META_HERO` is read only when `econV2` is true (a Legacy run with `C.GATES.economyV2` on) or for a version 3 profile under that switch (`hallOf`). With the switch off nothing changes.
- **Small fix (src/rules.js `bagCapacity`).** In CREATE the bag count now reads the hall the run will read: META_HERO under the switch in a Legacy run, otherwise META. Before this fix, a Legacy profile showed META's Deeper Pockets before START_RUN.
- **UI text (src/ui/ui-text.js `metaEffect`).** Before, the Vigor and Edge cards printed "+N % per rank" from a single number. For a rank list they now say "+3 % max health, then +1 %". The tooltip says "Every hero starts with 3 % more maximum health with rank I and 1 % more with rank II (4 % in all)." Edge reads the same way, with Power. These are draft words: Content can reword them, and the numbers come from the list. Level-60 cards are unchanged.
- **Sim (sim/lib/hall.mjs).** Arm `v3d` now reads `C.META_HERO` directly, with no copy and no price overrides, so the sim and the engine cannot drift apart. Arm `v2` is now a sim-side constant: +1 % a rank, 4 slots, the v2 prices. `applyHall` sets rank lists on the table, which is exact for every rank, instead of the old rank × mean. A cell without an arm resets the fields to the engine's values. The other arms keep their values.
- **Refund rule (decided; legacy.md 4.7 E5, draft): none.** A version 3 profile that bought at v2 prices keeps its ranks, its balance and its `spent`, and each rank plays the v3d effect at once. There is no second refund pass and no note, for three reasons. The switch is off by default, so only `?legacy=1` test profiles have bought under v2. Every effect change is upward. The only price that falls is Stormhawk's: a Hunter who paid 150 has paid 60 more than a later buyer. Deeper Pockets bought at 40 is not charged the extra 10. D160's refund (`hallV2`) is unchanged.
