## Notes for the team
- Engineer: `zoneDanger(level)` is not in the rules.js API, so the UI computes `ZONE_DANGER_STEP × max(0, M − ZONE_DANGER_FROM) / 10` from `R.C` (the 10 is the constant's unit, "per 10 levels"; rules.md table). Exporting `zoneDanger` (or a danger value per node in `mapView`) would remove this copy. ui-regress imports it from src/engine/combat.js for the expected values.
- Engineer: after a death in the boss fight the fight is gone, so `resurrectCharges(s).now` lists Second Breath again in the SUMMARY state. The UI decides the death-screen line from `summary.death.nodeType === 'boss'` and the held count, not from `now`.
- QA: the AUTO test helper never played zone travel (the director keys transitions off the UI action type); `autoRun` now sends TRAVEL_ON as the button does. Out of combat, autoplay itself does not run, so players are not affected.
- Lead: the boss frame's phase marks at 70 % and 40 % are fixed in hud.js (copies of P2_AT / P3_AT, not changed in M2 v3); a two-line change to read them from `R.C` when wanted.
