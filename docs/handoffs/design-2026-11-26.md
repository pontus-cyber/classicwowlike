## R2-1 (built, demo only, behind C.GATES.demo)
- **Rule:** the demo's end needs C.DEMO_END_WINS = **3 fights won in zone 2** (any kind, a Dimmed encounter included; `state.demoWins`, made at the first such win in a demo run). Leaving zone 2 with fewer (Road, Bell, TRAVEL_ON) ends the run early: outcome **`left`**, `demoEnd` with `early: true`, no zone line for zone 2, no demo block, summary `demoLeft { zone, wins, need, welcome }`. Spec demo.md 1.2a; engine-api.md 16. Why this rule and not the zone 2 elite: report section 2 (planner 99.5-100 % of exits meet it, the hurried bot 84-86 %, autoplay every run; the skipper's exit had 0).
- **The 60 welcome:** not paid on an early leave; it stays due (`profile.welcome` false) and the next run that is not left early pays it. A death pays it as before.
- **UI (draft lines, demo.js `DEMO_TEXT`):** zone 2's Bell button reads "End the demo run" (gold) or "End this run early" (muted red outline), class `demoexit` / `early`; its confirm asks "End the demo run?" / "End this run early?"; the map header shows "Demo end: N of 3 fights won here" / "Demo end reached: leave by a Road or the Bell"; before three wins the leave line reads "Leaving now ends this run early. Win two more fights in Greywater Fens to finish the demo; an early leave earns nothing for Greywater Fens."; an early leave's summary head: "The run has ended" · "Vex left Greywater Fens early" · "The demo ends after three fights won in Greywater Fens. This run won one there." · "Your first-run welcome waits for the next run." (when it does). No "You made it through" on it.
