## 2. Words used (content f3b8eea, docs/handoffs/content-2026-11-11.md)
- `texts.families[id].plural` / `.singular`: every contract title and sentence ("Cull outlaws in Millbrook Steadings").
- `texts.contracts.cull`, `.bounty`, `.delve`: the full sentence in tooltips, the reward window and the hub offer;
  `.hub`: the hub offer ("Stilt Haven has work on the board: Cull 2 reedfolk in ..."). The UI writes "an" before a vowel
  for "a {familyOne}" ("an outlaw"); the Content Designer may want the template to allow for it.
- `texts.prep[id].flavour`: the option tooltip's flavour line. `.rule` is used only for an option the UI has no effect
  line for; the UI's own effect lines carry the engine's numbers (count, slots, charges, radius).
- The UI's own short titles (tracker, toasts, map marks): "Cull {family} in {region}", "Bounty: {elite}", "Delve:
  {dungeon}". Fallbacks without content: the family id in words ("wild foes") and a built sentence.

## 5. Interpretations (draft: please confirm or change)
1. No HUD at the camp (as on class select); the Furnace starts with zone 1.
2. Keys: 1-8 for the board, A-I for the options in the engine's order, R, Enter; Enter has a 700 ms guard.
3. A held contract's colour is that of its number (k1 amber, k2 teal, k3 violet, k4 rose), the next free one on a clash.
4. The tracker shows on the map and in fights, not in the hub (the hub panel covers that column and shows the offer).
5. The hub offer comes first in the hub panel, since it closes when the player leaves.
6. A contract's XP and gold show on its own window, not with the fight's spoils.
7. The setting is saved; turning it on at class select changes the run on screen at once.
