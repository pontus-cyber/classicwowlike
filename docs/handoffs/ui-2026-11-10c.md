## Known issues
- A node tooltip's zone danger covers the enemies the fight is built with, not adds summoned during it. In a dungeon, a summoned add takes the full bonus (built as `normal`), so it can hit harder than the "up to" value shown.
- Mock mode (`?mock=1`) keeps its own 50 % Greater draught and has no Oaths or zone danger.
