## 2. How to test
- `node tools/build.mjs --out /tmp/ui-game.html`
- `node qa/browser/ui-regress.mjs --file /tmp/ui-game.html --parts R` (part R, new). Every part at 1366x768: `--sizes 1366x768`.
  A, M, N and R at 1920x1080: `--sizes 1920x1080 --parts A,M,N,R`.
- `node qa/browser/full-run.mjs --file /tmp/ui-game.html` (a fresh profile now plays the guided run; the twin takes `tutorial: true`).
- By hand: open game.html in a fresh browser profile and play zone 1. To see it again, use the Dev menu's "Reset onboarding" or Settings, "Reset hints" and "Play the guide again".

## 4. Known issues and open points (for the Lead)
1. The engine's `tutorialView.line` keeps G12 on top for the whole zone (it stays open until zone 1 is left), so G13's line
   never becomes `line`. The UI reads `open` and lets a line that has been read give way after 2 steps. The Designer or
   engineer may prefer G12's line to close once it has been shown (spec 2.4 "If not").
2. "Skip guide" asks one line first ("Skip the guide for this run? First-time hints stay on." with Skip / Keep it), as the
   task brief asks. Spec 2.2 says no confirmation. The Designer should settle which one stands.
3. Trigger readings to review (draft): H19 "far from a Road" is read as no Road among the moves and the node dimming within
   4 tolls (the view has no hop counts). H22 looks for a hub contract card (`.hub-contract` / `[data-hub-offer]`), which
   prep.js `buildHubOffer` does not mark today, so H22 does not fire yet. H07 fires on the LETHAL badge the client already
   draws. H12 fires on a level-up that brings a new spell.
4. Hints in the classic map (Dev only): the map hints (H15, H16, H18, H24, H26, H29) read the expedition map only.
5. The Dev menu's "Reset onboarding" is not built yet. Settings' "Reset hints" and "Play the guide again" do the same job.
6. Style snapshot (spec 7.1.6) not updated in this task.
