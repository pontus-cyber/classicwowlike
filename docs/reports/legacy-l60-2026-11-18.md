## Setup (D118)

  (sim/out/pass-v9v10 obs-*.json, pass-v12 table risk.json), warm-up 0.

- **Runs:** 300 per class per cell, seeds 1000-1299, every cell in both arms on the same seeds (paired). 10 800 runs.
- **Arms:** off = the engine's switches as built (`C.GATES.legacy` and `oruvathLegacy` off). On = every default-on
  switch plus `oruvathLegacy` (cell mark `or2`); `legacy` stays off, so every run is a level-60 run.
- **Engine:** src as at ae1fcaa (D157 build a1c4f18; the later commits change docs and sim only). Sim: the Camp bar

  `node sim/l60report.mjs sim/out/pass-l60`. Attribution arms: `bash sim/l60-arms.sh sim/out/pass-l60 "<arm>:<tokens>"`
  (scratch copies under sim/out/pass-l60/scratch-*, patched by sim/l60-patch.py; env CLASS, CELLS, RUNS).
- **What the switch changes in a level-60 run:** the class numbers (ORUVATH_SPELL / ORUVATH_TALENT: Frost Lance,
  Pyre Comet and Cinder Storm at power 21, Glacial Tomb 43, Feign Stillness 23, Heartseeker Shot 43 and -5 %,
  Barbed Arrow and Open Vein DoT, Field Dressing, Ferocity), autoplay's boss DoT rule (2.4.1 item 5), the sim Hunter's
  Camp pet step (2.4.1 item 6) and the sim Camp bar valuation (sim-2026-11-18c). Oruvath's scale is not used (it needs
  `legacy`). Check: the on arm with all four pieces taken back plays the off arm run for run (planner P0, 100 runs a
  class: **300 / 300 identical**, sim/samerecords.mjs), so these four are everything the switch does at level 60.

## Verdict

1. **Turning oruvathLegacy on breaks B6 PALL.** The PALL spread goes from 12.3 pp to **28.7 pp** (Rogue 61.7, Mage 70.3,
   Hunter **90.3 %**; the Hunter +22.7 pp paired). B6 PALL already fails with the switch off (12.3 pp, Hunter high), so
   the switch does not create the failure; it more than doubles it.
2. **The cause is the sim Hunter's Camp pet step** (legacy.md 2.4.1 item 6, Mend Companion kept on the Camp bar). With
   only that step taken back, the PALL Hunter wins 65.7 % (-24.7 pp against on, -2.0 against off) and its boss fights won
   fall from 95.1 to 69.1 %. The Hunter's class numbers move PALL by 0.0 pp (all taken back: 90.3 %). The Mage's +8.3 pp
   is its class numbers (Frost Lance about -3.3, Pyre Comet at power 21 about -3.7 when taken back; Cinder Storm and
   Glacial Tomb under 1 pp); the Rogue's +6.3 pp is Open Vein's DoT (its only number). With the pet step off and the rest
   on, PALL is 61.7 / 70.3 / 65.7 (spread 8.6 pp): still a fail by 0.6 pp, now Mage-high.
3. **B6 P0 fails in both arms** (off 9.7 pp, Hunter low at 18.0 %; on 9.0 pp, Rogue high at 34.7 %). On lifts the
   Hunter +14.0 pp (pet step and class numbers, about +5 each when taken back alone) and the Rogue +7.0 pp, all of it
   Open Vein's DoT (Rogue with the numbers back: 27.7 %, identical to off). With Open Vein at its rules.md value and the
   rest on, P0 would be 27.7 / 25.7 / 32.0 (spread 6.3 pp, each within 3.5 pp of the mean): a pass [inference: per-class
   arms combined; each class's runs read only its own numbers].
4. **B1 passes in both arms** (planner P0 24.2 → 30.8 %, +6.6 pp, inside 20-35 %). B21 passes in both (Z1-Z2 9.2 / 8.0 %,
   Z3-Z4 3.9 / 3.4 %, Z5-Z6 and Camp 6.2 / 6.9 %, boss 74.5 / 73.5 % of deaths). B26-B28 pass in both (ratios 0.05 / 0.09,
   0.58 / 0.44, 0.20 / 0.37). B29 P0 fails off (3.9 %) and passes on (8.7 %, the Hunter's Final Dark share 25 %).
5. **One-button P0 wins 0 of 900 in both arms** (reach 15.2 / 15.0 %).
6. **Side readings:** the sim Camp bar valuation (sim-2026-11-18c) changes no level-60 run (prevent arm identical to on);
   autoplay's boss DoT rule moves the Hunter by about 1 pp and the Mage by 0. Per class, B28 no longer bites the
   Hunter with the switch on (noAoe 82.0 % against 90.3 %; with the pet step off 44.3 %), and B27 bites the Mage much
   harder (noCleanse 19.3 % against 65.7 % off); the pooled ratios still pass.
7. **Not met / open:** B6 PALL with the switch on. The lever is the Hunter's Camp pet step at level 60 (keep it for
   Legacy runs only, or price Mend Companion against the fill spell at level 60), then the Mage's 0.6 pp; B6 P0 needs
   Open Vein's +15 % kept to Legacy runs (or the Rogue trimmed at level 60). Both are calls for the Designer and the
   Lead; nothing was changed.
