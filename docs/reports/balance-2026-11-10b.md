# Balance report 2026-11-10b: M2 v4 measure (M2 task 2.3, the deciding measure)

From: Simulation & Balance Engineer. For: the Lead and the Lead Game Designer. No rules constant, content value or spec was changed. Every proposal below was measured in a git-ignored scratch copy of src/ and sim/ (sim/out/xp4/*); the decisions are the Designer's and the Lead's.

## Verdict
**P1: 40 of 45 pass; P2 failures: B19, B20, B22 (quest share), B29.** All checks: 61 of 73 pass (11-10: 53 of 72; P1 35 of 45).

**M2's done-when is not met.** balance.md 2 stops tuning when all P1 metrics pass and at most 2 P2 metrics fail; D40 closes M2 when every P1 passes, with B19, B20 and B22 not blocking. Five P1 checks fail (B6 PALL, B7 hunter, B16 end boss, B21 Z1-Z2 and Z3-Z4), and B29 is a P2 failure outside D40's list. Three of the five P1 misses and B29 come from one sim-side choice, the rogue's default tree (section 2); the other two need a Designer decision (sections 1 and 3).

### 2. Rogue default tree: B16 end boss, B21 Z1-Z2 and Z3-Z4 (P1) and B29 (P2) follow the tree flip
The tree rule chose rogue tree 1 Shadowcraft (25.0 %, interval 23.2-26.9 %) over tree 2 Venomcraft (23.1 %), a 1.9 pp gap inside both intervals. Shadowcraft reaches the boss in 56 % of runs (Venomcraft 77 %) and wins 45 % of its boss fights; its runs die in Z1-Z2 21.9 % and Z3-Z4 19.6 %, and its fights are long (end boss 49 rounds, dungeon boss 18).

Planner P0 checks from this pass's own cells (2 000 runs per class, no new runs), pooled with each rogue tree:

| Check | rogue tree 1 (as measured) | rogue tree 2 (11-10 default) | Band |
|---|---|---|---|
| B1 planner P0 | 24.7 % | 24.1 % | 20-35 |
| B21 runs dying Z1-Z2 / Z3-Z4 / Z5-6 | 13.1 / 10.1 / 3.6 % | 11.7 / 4.0 / 4.1 % | <= 12 / 3-10 / 2-8 |
| B21 boss share of deaths | 64.4 % | 73.8 % | 55-80 |
| B16 end boss rounds | 46 | 42 | 30-45 |
| B29 Final Dark | 27.4 % | 19.1 % | 5-20 |
| B22 dungeon / quest share | 18.7 / 51.9 % | 24.9 / 45.3 % | 15-35 / <= 45 |
| B38 spread / Z6 | 7.9 pp / 82.1 % | 5.7 pp / 82.9 % | <= 10 / <= 85 |
| B11 minutes | 46.2 | 45.2 | 40-50 |

With Venomcraft as the rogue's tree, B16, B21 and B29 pass (B21 Z1-Z2 0.3 pp under its limit) and B22 quest share is 0.3 pp over. The cost is at PALL: rogue tree 2 wins 54.1 % against 61.5 % with tree 1 (paired), so B6 PALL would widen (about 22 pp) and the PALL planner fall by about 2.5 pp.

Proposal for the Designer (bot rule, balance.md 1.3, not a constant): either (a) a tie rule for the default tree, for example keep the previous pass's tree unless another tree is better by more than the 95 % interval, which keeps Venomcraft; or (b) choose the default tree per profile (P0 tree for P0 cells, best PALL tree for PALL cells). Separately, Shadowcraft is the game's slowest and riskiest rogue path at P0 (long fights, 41 % of its runs die before Z5), which a human playing it will feel; worth a look independent of the bots. Not measured as a rules change.
