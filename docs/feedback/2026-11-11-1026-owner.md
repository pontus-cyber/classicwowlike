# Owner feedback 2026-11-11 10:26
[stated] The game should feel like you level up your specific class. Ideas: the talent tree capped so you must level it up; some abilities capped; progression slightly more linear: the first runs very hard to pass, so you need a couple of runs, and Echoes gained per run go up so unlocks come faster after each run and you feel you are building your character. Early on, noticeable upgrades so the player is hooked. An overall reduction of damage numbers before they escalate (divide by 2 or 3). The Echo board stays as an account-wide progression system, while each character levels individually: you create your character once and keep playing it, instead of creating one each run. "Just an idea, start thinking about it."
Lead actions: Lead Game Designer writes a meta-progression v2 design (M3): persistent characters per class with their own progression, capped talents and spell ranks unlocked by it, the early-hook curve, Echo income, and a number-scale reduction; with options, defaults and a sim prototype; pitch to the owner before any build.
