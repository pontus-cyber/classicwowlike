## Lead's view (draft, sent to the owner)
- Fits: Classic feel (respec fee, sets in a bank), build experimentation, retention; consistent with one character per class.
- Risks: permanent gear and talents raise power over time, which works against "a skilled player wins from a fresh file" (18:58); in-run gear drops lose meaning if bank sets are better; in-run levelling needs a new purpose; much balance work across trees.
- Proposed shape: talents as a pre-run loadout from unlocked talents with the same point budget for everyone (unlocks add options, not points); bank sets carry a set effect that changes how a tree plays, with modest or no stats (stats still come from in-run drops); cheap respec; in-run levels give spells, ranks and stats. Goes into meta v2 redesign (M3), measured for fresh-file skill ceiling.
