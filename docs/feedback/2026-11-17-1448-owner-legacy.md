# Owner decision 2026-11-17 14:48: Legacy progression (Lead chat)

Status: owner decision (direction). Details to be specified by the Designer as draft for owner steering.

Owner's words (summary, close to verbatim):
- "Legacy run points": an account-wide progression system where you earn permanent upgrades from each run.
- Each character (hero) has its own level from 1 to 25; 25 is max level.
- A good playthrough should reach level 25 within 6 to 8 hours of game time.
- A player can optimize for beating the game (quests, dungeons, clearing, winning) or for levelling the character.
- From a certain stage, for example level 20, the player can spend Legacy points or Legacy currency to unlock different talent trees, start building sets, and so on.
- "This is the exact way we should do this."

Owner answers to the Lead's two questions (AskUserQuestion, 14:5x):
- Hero level is kept across runs and rises over 6-8 hours of play across several runs; zones scale to the hero's level.
- On death the run ends and pays Legacy points; the hero keeps level and XP.
