# Lore

World, history, factions, characters and tone for the game. Written in a separate lore chat with the owner; the Content Designer turns it into game text (src/content/) and the Lead keeps it consistent with the specs.

## Rules
- Original only: no names, places, characters or text from existing games, books or films (docs/README.md).
- Canon that already exists in the game and must be respected (or changed deliberately, with a note to the Lead): the six zones and their regions (src/content/zones.js), enemy families (src/content/enemies.js), the end boss Oruvath, the Unlit Star, and the Sunken Observatory (docs/specs/rules.md 10), the Dimming, Shardfall, Roads and the Homeward Bell (docs/specs/expedition.md, src/content/texts.js), classes Rogue, Mage, Hunter.
- One topic per file: world.md, history.md, factions.md, zones/<zone>.md, characters.md, style.md (tone and naming rules).
- Mark each file's status at the top: draft / approved by owner.

## How it reaches the game
The lore chat commits files here (or the owner pastes them into docs/feedback/). The Lead logs approved lore in docs/BACKLOG.md and schedules content work for it.
