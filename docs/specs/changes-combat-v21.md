# Spec changes combat v2.1: the opening decides the fight

Owner: Lead Game Designer (combat). For: Core Gameplay Engineer (src/), Simulation & Balance Engineer (sim/), UI/UX Engineer, QA. Date 2026-11-10.
Every changed or new line in docs/specs/combat-v2.md and docs/specs/rules.md section 7 and 13 is marked "(combat v2.1)"; the rules and evidence are in combat-v2.md section 16. Decisions D55-D59 in docs/DECISIONS.md.

Problems [source: docs/reports/balance-2026-11-10d.md, docs/handoffs/sim-2026-11-10d.md]: P1 mashing reaches the boss as often as autoplay (78.7 % against 79.8 %, B49); P2 the planned opening adds only +2.2 pp reach (B48) because the fights that kill are long elite and dungeon-boss fights decided after round 5 (B50 control: autoplay's opening saves 36.6 % of the masher's deaths, the opener's 39.0 %); P3 setup options are almost never chosen and the Rogue Ambushes in 92 % of multi-enemy fights (B51); P4 B52 as a share of windows cannot pass (the masher's few windows are on its own target); P5 the end boss got easier (B1).

Type: **number** = src/constants.js only; **mechanic** = engine code (exact behaviour in the last column); **bot** = sim/ change; **target** = combat-v2.md 12 metric.
